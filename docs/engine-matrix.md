# Engine matrix

Generated by `testing/engines-test.c --matrix` from the table in
`app/engines.c`: the engine a session runs for each system, host first.
`-` means no common engine, so each device runs its own core as before.
A note after `/` is the advice shown when a gpSP game is not linkable.
